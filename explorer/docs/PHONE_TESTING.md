# Checking the Explorer on a phone

Start the synthetic demo as described in [Getting started](../../docs/GETTING_STARTED.md).
Use your own private connection or SSH tunnel to access the local server from
your phone. The viewer has no authentication layer.

Check the complete path: experiment family → run table → overview → trade chart.

- Pan and pinch the chart, then use Recenter.
- Move to the next and previous trade.
- Switch M1, M5, M15, and H1 views.
- Check that entry, exit, stop, and target markers stay aligned.
- Rotate the device and check that controls remain reachable.
- Change the device timezone and confirm that displayed native times stay fixed.
- Keep the synthetic-data label visible throughout the demo.

The demo is useful for checking the interface. Research-data integration checks
require your own admitted data and completed run artifacts.
